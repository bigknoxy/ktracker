## Ticket Synopsis
The MVP application aims to provide weight, workout, and task tracking for individual users, featuring a dashboard homepage. Core requirements include daily weight entries, workout session logging, task management, BMI calculation, goal setting, and RESTful API endpoints. The technical stack is TypeScript, Bun, PostgreSQL, Prisma ORM, Docker, and basic authentication. Non-functional requirements include performance, scalability, security, and maintainability. Initial data models and endpoints are specified, but no implementation exists yet.
